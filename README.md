# 🏠 Lavi mwen - Jogo com Mario

Jogo simples de simulação de vida onde você controla o Mario.

## 🎮 Como Jogar

- **Clique** com o mouse em qualquer lugar da casa para o Mario andar até lá.
- **Clique perto** dos objetos para interagir:
  - 🛏️ Cama → Dormir (recupera energia)
  - 🚿 Chuveiro → Tomar banho
  - 🧊 Geladeira → Comer
  - 📺 TV → Assistir televisão
  - 🚗 Carro → Entrar no carro
  - 🚪 Porta → Sair de casa

## 📊 Status

- **Enèji** (Energia)
- **Lajan** (Dinheiro)
- **Grangou** (Fome)

## 📁 Arquivos do projeto

- `index.html` → Código principal do jogo
- `mario.png` → Imagem do personagem Mario

## 🚀 Como rodar

1. Faça o upload dos arquivos `index.html` e `mario.png` no repositório
2. Ative o GitHub Pages:
   - Vá em **Settings** → **Pages**
   - Em "Source" escolha a branch `main`
   - Clique em Save
3. Acesse o link do seu GitHub Pages para jogar
